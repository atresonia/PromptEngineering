# Session 1 - 10/5/26
## Goals
1. Create a rubric/clear description of a good requirements doc
2. Run a controlled prompt comparison - change one variable at a time across 3 prompt variants (keeping transcript, model the same as the control) and score each against the rubric
3. Explain why the prompt won/had the highest score.
4. Name what an agent would need to act on the resulting doc: inputs, tools, a definition of done, and a check it can run.
## Details
We take an example conversation from Utrecht University's REConSum repo: two analysts interview a client about a portal for a fictional International Football Association covering budgets, match reporting, schedling, referee assignment, and fan notifications.
Features:
1. 40 minutes: 133 turns, ~5,500 words
2. Messy - fillers, cross talk and misrecognitions ("FAA" for IFA, "defense" for fans)
3. Role-played - lecturer plays the client. Real speech - but simlated stakes
4. References documents we might not have
